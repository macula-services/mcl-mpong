# Changelog

All notable changes to this project are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and
this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Changed

- **mcl_om `~> 0.27`.** 0.27.0 drops barrel_docdb and with it the rocksdb C++
  build this service paid for without holding any read model, and its boot
  claims carry the `MCL_BOX` and service-name labels, so the realm's Providers
  desk shows which box each bot runs on. Resolved from hex as 0.27.0.
- **The image builds in the team's `macula-ci-otp` and runs on
  `macula-pq-runtime`, both by digest** (OTP 28.4.3, Rust and rebar3 pinned),
  instead of the floating `erlang:28-alpine`, a floating Rust and rebar3 from
  S3's unversioned latest. CI lints and tests in the same `macula-ci-otp`
  digest. The pin test now fails when the Containerfile and `lint.yml` name
  different images, or when the VM running the suite is not the release
  `.tool-versions` names (28.4.3; it was 28.4.2).
- The image carries `org.opencontainers.image.revision`, the commit it was
  built from.

### Added

- The port of `hecate-services/hecate-mpong-bot` onto `mcl_om` and macula 12:
  two bots find each other on the mesh and play pong, host and challenger.
- `mcl_mpong_facts`, the fact contract: six `_v2` topics under
  `io.macula/mcl-mpong/mpong/match/`, pinned key for key by tests that also read
  each payload back through macula's CBOR codec.
- Mesh measurement carried on the match facts: frames and moves seen and missed
  (`mesh_gauge`), paddle round-trip latency with the host's hold time taken out,
  so no clock sync is assumed, and the stations each end's pool is on.
- `find_match`, the coordinator: seek, host or challenge, seat reserved or
  denied, churn pause and abandon. Every fact is attributed by its verified
  publisher. Role timers carry the epoch they were armed in, so a timer from an
  earlier spell of a role cannot cut a later one short.
- Health reports the match: `degraded` after 15 minutes without an opponent.
- The scaffold, generated by `rebar3 new mcl_service` from mcl-om's template:
  release, `Containerfile`, compose file, CI, `/health` on 8472.

### Changed from hecate-mpong-bot

- No event store (reckon_db, evoq), no projection or query apps, no spectator
  HTTP API and no champion registry. A match lives in the engine process. A
  scoped waiver of the event-sourcing default, for this demo.
- Topics moved off `beam-campus/hecate/mpong/*_v1`. No payload carries a
  boolean; `alive` and `paused` are 1/0.
- The image build ignores pushes that touch only docs or scripts, so they do
  not roll the fleet.
- Built on `mcl_om ~> 0.26.2`, the floor that refuses to run on an identity key
  it could not save. `scripts/is-mcl-om-resolved-from-hex.sh` asserts the
  version a clean resolve from hex actually builds.
